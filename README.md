# ELDEN 1

A Windows-first Formula racing game project.

## Visual target
ELDEN 1 is being built around a premium motorsport presentation: detailed licensed-or-original 3D vehicle assets, realistic circuit environments, physically based materials, cinematic lighting, and a readable T-cam racing view.

**Quality rule:** placeholder cubes, primitive polygon cars, and unfinished greybox tracks are not acceptable as final player-facing content. If a required production asset is not ready, the feature stays clearly marked as work in progress.

## Engine
Godot 4.x, using Forward+ rendering for desktop. The project targets Windows 10/11 64-bit.

## Current status
This repository is at the foundation stage. No playable race, finished car model, finished circuit, or Windows executable is claimed yet.

## Planned milestones
1. Establish project structure, rendering baseline, and presentation direction.
2. Integrate a high-quality original Formula-style car model and cockpit/T-cam cameras.
3. Build a detailed test circuit with believable trackside assets and lighting.
4. Implement vehicle physics, tyres, braking, gears, and assists.
5. Add race weekend flow, AI, flags, penalties, damage, and HUD.
6. Add graphics settings and verified Windows builds.

## Running
Install Godot 4.x (standard desktop editor), open this folder's `project.godot`, then run the project once the initial scene is added.

## Asset policy
Only use assets with clear permission for redistribution or original assets created for this project. Do not bundle commercial F1 game assets or imply official Formula One licensing.
